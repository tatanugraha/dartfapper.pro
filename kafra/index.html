KAFRA GUARD · FREE

Get started

Protect your Ragnarok server with Kafra Guard for free: one login server, up to 50 players online and 10 allowed DLLs. Kafra Guard Pro adds sub-servers, more players, the protection switch, client limits and player module reports.

  1. 1

    Create your server

    Name it the way your players know it. You become its owner; sign in with the same Google or Discord account.

  2. 2

    Download the owner tools

    Windows tools for you (not for players), and the kit for your rAthena server. Check the SHA-256 before you run anything: in PowerShell, Get-FileHash .\file.zip.

    ToolVersionSHA-256Download
  3. 3

    Install the gate on your VPS

    The gate checks every player's client. It runs on the same machine as your login-server.

    You need: Ubuntu 24.04, a domain or subdomain pointing to the VPS (e.g. gate.myserver.com), and ports 80 (TLS certificate) and 8443 (gate) open in your firewall.

    Easiest: open KafraGuardConfig, fill in your server and gate domain, then click Install to VPS and enter your SSH login. It does everything below for you.

    By hand: click Export Installer VPS in KafraGuardConfig, upload the folder to the VPS, then run:

    cd kafra-guard-vps
sudo bash installer/install.sh

    At the end it prints your gate URL. Your keys are in the gate config:

    sudo cat /etc/gameshield/gate.json

    ownerKey is for step 4. internalKey and internalPort are for step 5.

    Gate installed before November 2026?

    Its gate.json has no ownerKey or internalPort yet. Generate a key with openssl rand -hex 32, add "ownerKey": "<that key>" and "internalPort": 8444 to /etc/gameshield/gate.json, then sudo systemctl restart gameshield.

  4. 4

    Connect the gate

    The dashboard reads players and builds from your gate with the owner key. It is checked before it is saved, and stored encrypted.

  5. 5

    Install the rAthena module

    A small login-server module that only lets in players running your protected client.

    Upload the server-kit folder to the VPS, then run it from your rAthena folder. It copies the module, wires it in (with backups), installs OpenSSL and rebuilds the login-server:

    cd ~/rathena
bash /path/to/server-kit/kafraguard-install.sh

    Then edit conf/kafraguard.conf:

    license  = (the license from step 6)
mode     = session
gate_port = 8444        # gate.json "internalPort"
gate_key  = ...         # gate.json "internalKey"

    Run the grants in sql/kafraguard-login-grant.sql once, and restart the login-server. A good start logs Kafra Guard active: licensed to …. If the script stops with ANCHOR NOT FOUND, follow KAFRAGUARD-INSTALL.md in the kit.

  6. 6

    Generate your license

    Free licenses last 30 days, for one login server and up to 50 players online. Generate a new one any time before it expires and paste it over the old one.

    License — paste it into conf/kafraguard.conf, then restart the login-server:
    Server IDExpiresMax onlineIssuedCopy
  7. 7

    Patch the game client

    Players only get in with your protected client.

    Open KafraGuardPatcher, choose your client EXE and patch it. Ship the patched EXE together with GameShield.dll in your client download or patcher.

    Builds you publish with KafraGuardConfig are accepted right away. Any other build shows under Kafra Guard → Client builds the first time someone logs in with it; click Approve once and it works for everyone.

    Test it: log in with the patched client (allowed), then with an unpatched one (refused, and logged by the login-server).

Owner tools (Super Admin)

Listed in step 2 for every signed-in user. Host the files yourself (HTTPS) and paste their SHA-256.
